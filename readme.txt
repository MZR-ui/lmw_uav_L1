# UAV Workspace (uav_ws) 介绍与架构说明

**生成时间**: 2026-04-01

本文档对当前的无人机 ROS (Robot Operating System) 工作空间 `uav_ws` 的代码内容、模块划分与整体架构进行详细解析，帮助开发者快速理解并上手本代码库。

## 1. 整体架构与工作流

本系统基于 **ROS Noetic** 构建，采用模块化的组件设计思路，通过标准的 ROS 通信机制（Topics / Services）在多个独立节点之间传递信息。

系统架构自底向上可大体分为以下几个层次：

- **硬件/驱动层**: 负责与底层硬件直接通信，如飞控（Flight Controller）、遥控器接收机和云台等。涉及的包有 `msp_interface`、`remote_info`、`gimbal_control_serial`。
- **感知与数据处理层**: 负责各类传感器数据的接入、处理和转换。涉及的包为 `sensing`。
- **子任务控制层**: 将具体的飞行或执行动作封装为原子任务（Subtasks）。涉及的包为 `subtask`。
- **任务调度与管理层**: 负责无人机的整体状态机管理、高级任务规划与决策。涉及的包为 `task_manager`。
- **启动与集成层**: 统筹各模块的配置和启动参数，包含在 `uav_bringup` 中。

## 2. 核心功能包详解

项目包含以下几个主要功能包（Package），它们位于 `src/` 目录下：

### 2.1 硬件通信与底层驱动

- **`msp_interface`**
  - **功能**: 使用 MSP V2 (MultiWii Serial Protocol) 协议与飞行控制器（如 Betaflight / iNav）进行串行通信的接口层。
  - **依赖与作用**: 依赖 `serial` 进行串口读写，向飞控发送控制指令（如姿态、油门），同时读取并发布飞控的状态信息（如 IMU、电池等）以供上层使用。

- **`remote_info`**
  - **功能**: 遥控器接收机数据处理。
  - **依赖与作用**: 解析 IBUS 等遥控器协议，将遥控器的通道拨杆数据解析转换为 ROS 标准消息，常用于切换模式（手动/自动）或直接介入控制。

- **`gimbal_control_serial`**
  - **功能**: 云台控制的串口驱动程序。
  - **依赖与作用**: 通过串行通信发送角度控制指令给相机云台，通常用于目标跟踪或巡航拍摄时的视角稳定与调整。

### 2.2 数据感知与处理

- **`sensing`**
  - **功能**: 感知层，负责视觉、激光雷达或其它传感器的数据接入。
  - **依赖与作用**: 引入了 `image_transport`、`sensor_msgs` 和 `tf2_ros`。负责处理图像流、传感器标定转换与坐标系管理（TF），为自动巡航、目标识别提供数据支撑。

### 2.3 任务逻辑与规划

- **`task_manager`**
  - **功能**: 核心的顶层任务管理与调度节点。
  - **依赖与作用**: 作为系统的“大脑”，它订阅各个底层（如 `remote_info`）的状态和感知数据，根据业务逻辑进行状态机切换，下发具体的子任务指令。

- **`subtask`**
  - **功能**: 基础动作和控制逻辑的封装。
  - **依赖与作用**: 依赖于 `task_manager` 下发的指令，执行具体的、单一的功能片段（如起飞、降落、悬停、轨迹跟随等），再把具体的控制量发给底层的 `msp_interface`。

### 2.4 系统启动与演示

- **`uav_bringup`**
  - **功能**: 系统的启动入口包。
  - **作用**: 包含了一系列的 `.launch` 文件与配置参数。主要作用是能够一键拉起上述所有需要的节点，设置正确的串口号、波特率与初始状态。

- **`demo_pkg`**
  - **功能**: 示例包。
  - **作用**: 提供一些基础的例子或测试脚本，方便开发者验证某一单独功能模块或通信机制。

## 3. 开发与编译指南

由于这是标准的 ROS Catkin 工作空间，可以使用标准流程进行编译：

```bash
# 进入工作空间根目录
cd /path/to/uav_ws

# 编译所有包
catkin_make

# 刷新环境变量
source devel/setup.bash
```

开发新功能时，请确保：
1. **模块解耦**: 底层驱动只负责协议转换，高层逻辑只负责决策，避免跨层直接耦合。
2. **依赖管理**: 若新增使用了其他 ROS 组件，请务必同步更新对应包的 `CMakeLists.txt` 和 `package.xml`。
